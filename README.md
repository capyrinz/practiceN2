# Кофейня «Зерно»

Учебный веб-проект кофейни на Python/Django: витрина с меню, корзина и оформление
самовывоза, личный кабинет с чеками PDF, блог, панель администратора со статистикой
продаж и drag-and-drop студия стикеров на стакане.

## Что внутри

**Клиент**

- каталог с категориями, поиском и карточкой товара;
- корзина в сессии (до 20 шт. одной позиции);
- оформление заказа: время самовывоза, комментарий, проверка на прошедшее время;
- регистрация и вход, история заказов со статусами и пошаговым индикатором;
- чек PDF (ReportLab + QR-код на публичную страницу заказа);
- стикер-студия: перетаскивание стикеров на макет стакана, масштаб, поворот,
  удаление; дизайн сохраняется в заказе;
- блог с обложками и временем чтения.

**Администратор** (`/manage/`)

- обзор: KPI, последние заказы, топ позиций;
- заказы: фильтры по статусу/дате/поиску, смена статуса, комментарий клиенту,
  удаление отменённого заказа, чек PDF;
- товары и категории: создание, редактирование, скрытие, фото;
- стикеры и статьи блога: CRUD и публикация;
- пользователи: поиск и блокировка;
- статистика: выручка и заказы за 14 дней, доли категорий, статусы, топ позиций.

## Стек

- Python 3.14, Django 6.1.3, SQLite;
- шаблоны Django + Bootstrap 5.3.3 (локально, без CDN);
- Chart.js 4.4.4 (локально) для графиков;
- ReportLab 5.1 + qrcode для чеков PDF;
- Pillow для изображений;
- шрифты DejaVu лежат в `shop/static/fonts/` — PDF с кириллицей работает без
  системных шрифтов.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py seed_demo       # демо-данные: меню, блог, 20 заказов
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/

Демо-доступы:

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `admin12345` |
| Клиент | `client` | `client12345` |
| Клиенты | `client2`, `client3` | `client12345` |

`seed_demo` идемпотентна: повторный запуск не дублирует записи, а заказы создаёт
только в пустой базе. Полный сброс: удалить `db.sqlite3` и повторить
`migrate` + `seed_demo`.

## Тесты


45 тестов: витрина и фильтры, корзина и лимиты, оформление и снимок цен,

## Настройки окружения

Значения по умолчанию рассчитаны на локальный запуск. Для другого окружения:

- `DJANGO_SECRET_KEY` — секретный ключ;
- `DJANGO_DEBUG=0` — выключить отладку;
- `DJANGO_ALLOWED_HOSTS=example.com,127.0.0.1` — разрешённые хосты;
- `SITE_URL=https://example.com` — база для QR-кода в чеке;
- `DJANGO_CSRF_TRUSTED_ORIGINS` — доверенные origin'ы через запятую.

Медиа (фото товаров и обложки) складываются в `media/`.

## Ограничения

Оплата не подключена — только самовывоз и оплата на кассе. Нет доставки,
e-mail/SMS-уведомлений, комментариев в блоге и отзывов. Корзина и дизайн стакана
хранятся в сессии, поэтому не переносятся между устройствами. SQLite и
`runserver` подходят для учебного запуска, не для нагрузки.
